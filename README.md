# Predictive parametric inference of LIB degradation

Public-code notebook release for the PBS emulator, Bayesian full-trajectory inference, and early-to-late degradation prediction workflow.

## Repository layout

- `notebooks/PBS emulator training.ipynb`: trains the PBS emulator and exports emulator-validation figures.
- `notebooks/Exp preprocess.ipynb`: preprocesses raw Tongji files into a long-format trajectory table.
- `notebooks/Experiment Bayesian inference.ipynb`: performs trajectory matching, Bayesian effective-parameter inference, and early-to-late prediction.

## Expected local data layout

- `data/pbs/pbs_lhs_400/scan_metadata.json`
- `data/pbs/pbs_lhs_400/scan_summary.csv`
- `data/pbs/pbs_lhs_400/life_soh_csv/*.csv`
- `data/tongji/raw/*.pkl`
- `data/tongji/battery_dataframe.csv`
- `data/tongji/tongji_capacity_trajectories.csv` generated by `notebooks/Exp preprocess.ipynb`

Generated artifacts are written to `outputs/cache/` and `outputs/figures/`. Data, trained cache artifacts, generated figures, and manuscript files are excluded from this repository.
